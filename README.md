## 🛡️ Projetos em destaque

### [WinSecAudit](https://github.com/PatrickCarvalho17/winsec-audit)
Ferramenta PowerShell que audita postura de segurança em endpoints Windows. Analisa **39 vetores em 5 categorias**, gera score de 0-100 e mapeia cada check para **CIS Controls v8** e **NIST CSF**.
